# Показатели по перевозчикам

Расчёт из практики 9 по рейсам за апрель и май.
Из папки, в которой лежит `final_project`, выполни три команды.

```powershell
cd final_project
python -m pip install -r requirements.txt
python run.py
```

Отчёт появится в `reports/report.md`, таблица — в `data/processed/kpi_by_carrier.csv`.
